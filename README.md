# codes
Códigos de apoio as aulas desenvolvidos em Python 3.12

** Chat - cliente e servidor de chat com comandos simplificados do protocolo IRC (Linux/Windows)

** Jogo_Velha - jogo da velha em modo texto e modo gráfico (Linux/Windows)

** Napster - clone do serviço Napster para uso de P2P (Windows)

** Penalty - jogo de tabuleiro de cobranças de pênaltis, modo texto e modo gráfico (Linux/Windows)

** PyNetCat - utilitários para experiências com conexões TCP/UDP e protocolos da camada de aplicação (Linux/Windows)

** Pynetlab - testador de vazão similar ao Iperf (Linux/Windows

** Mac-Telnet - acesso remoto em linha de comando usando endereçamento MAC (Linux)
