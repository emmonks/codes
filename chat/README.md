# Chat

## Servidor

- Para encerrar o servidor usar o comando "shutdown" na console

## Cliente
- /join - cria ou ingressa em um novo canal de chat
  - Exemplo: /join Redes
- /msg - envia uma mensagem no privado
  - Exemplo: /msg emmonks Alo
- /list - lista os canais e usuários online
  - Exemplo: /list
